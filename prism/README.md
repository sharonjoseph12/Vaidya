# PRISM Diagnostic Platform

A smartphone-based, offline-capable, multimodal AI diagnostic platform.

## Architecture
- **Layer 1 (Sense)**: Multimodal biomarker extraction (rPPG, audio, visual)
- **Layer 2 (Reason)**: Causal inference networks
- **Layer 3 (Project)**: Digital twin health trajectory forecasting
- **Layer 4 (Act)**: RL-based intervention optimization
